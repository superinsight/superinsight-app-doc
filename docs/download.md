# Installation

Open Superinsight in your browser. No download or installation is required.

[Launch Web App :material-web:](https://app.superinsight.me){ .md-button .md-button--primary }

## Open the web app

1. Go to [app.superinsight.me](https://app.superinsight.me).
2. [Sign in](guide/sign-in.md) with the mobile number on your account.
3. Follow the [Quickstart Guide](quickstart.md) to create your first case and report.


!!! question "Need Help?"
    - Check the [Quickstart Guide](quickstart.md)
    - Visit the [How To Guide](guide/guideOverview.md)
    - Contact support through [Live Help](https://app.superinsight.me) or [help@superinsight.ai](mailto:help@superinsight.ai)

!!! warning "The desktop app is deprecated"
    The Superinsight desktop app has been deprecated and is no longer supported. If you were using the desktop app, use the web app at [app.superinsight.me](https://app.superinsight.me) instead.
