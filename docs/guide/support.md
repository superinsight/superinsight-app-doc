## How to get help

<div class="grid cards" markdown>

-   :material-message-text:{ .lg .middle } __Live Help__

    ---

    Chat with our team inside the Superinsight app. This is usually the fastest way to get help.

    1. Open Superinsight
    2. Look for **Live Help** in the app
    3. Send a short message describing what you’re trying to do

    ![Live Help](../assets/images/tutorial/live-help.png)

-   :material-email:{ .lg .middle } __Email__

    ---

    Prefer email? Reach us at [help@superinsight.ai](mailto:help@superinsight.ai).

    Please include:

    - Your name and the email on your Superinsight account
    - What you were trying to do
    - What went wrong (and a screenshot if you have one)
    - The case name, if it relates to a specific case

</div>

## Common problems

### I can’t sign in

1. Confirm you’re using the correct email for your Superinsight account
2. Try resetting your password if prompted
3. If you recently changed your email or phone number, make sure it’s verified
4. Still stuck? Contact us through [Live Help](https://app.superinsight.me) or [email](mailto:help@superinsight.ai)

### My file isn’t uploading or processing

1. Check that the file finished selecting / uploading
2. Wait a moment — larger medical records can take longer to process
3. Refresh the page and check whether the file status changed
4. Try uploading again if it failed
5. If it still fails, tell Support the file name and what you see on screen

### My report is taking a long time

1. Open the case and check the report status
2. Wait for processing to finish before downloading
3. If it stays stuck for a long time, contact Support with the case name and report type

### I don’t know where to start

Begin here:

1. [Open or install Superinsight](../download.md)
2. Follow the [Quickstart Guide](../quickstart.md)
3. Explore the [How To Guide](guideOverview.md) for specific tasks
