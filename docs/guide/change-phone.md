# Change Your Mobile Number

Update the mobile phone number on your Superinsight account from **Settings**. That number is the one you use to sign in. After you verify the new number, the next sign-in uses it.

Use this page when you want to update your phone number, change your mobile number, or change the number Superinsight texts at login.

## Steps

1. Open Superinsight at [app.superinsight.me](https://app.superinsight.me) and click **Settings** in the left sidebar.
2. Under **Account Information**, find **Mobile Number**.
3. Click **Change**.
4. On **Change Mobile Number**, choose the country code and enter the new number in **Mobile number**.
5. Click **Send Code**. Superinsight shows **SMS code has been sent**, and the button changes to **Sent**.
6. Enter the code from the text in **Enter SMS code**.
7. Click **Verify**.

!!! success "You're done when…"
    Superinsight shows **Your Mobile Number has been updated**. The next time you [sign in](sign-in.md), use this new number.

## The SMS code did not arrive

1. Confirm the country code and the new number.
2. Confirm that phone can receive text messages.
3. Return to **Change Mobile Number** and click **Send Code** again.
