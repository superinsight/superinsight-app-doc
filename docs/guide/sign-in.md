# Sign In

Sign in to Superinsight with the mobile phone number on your account. Superinsight sends an SMS code to that number. Enter the code to open the app.

Use this page when you need to log in, when you did not receive a text, or when you want to know which phone number Superinsight uses for sign-in.

## Steps

1. Open Superinsight at [app.superinsight.me](https://app.superinsight.me).
2. Choose your country code.
3. Enter your **Mobile Phone number**. Use the number saved on your Superinsight account. If you recently changed it, use the new number.
4. Click **Sign In**.
5. When the **SMS code:** dialog opens, enter the code from the text message.
6. Click **Submit**.

!!! success "You're done when…"
    Superinsight opens your account.

## The SMS code did not arrive

1. Confirm you entered the mobile number currently on the account, including the country code.
2. Confirm that phone can receive text messages.
3. Click **Cancel** on the **SMS code:** dialog, then click **Sign In** again to request a new code.

If you need to put a different number on the account, sign in with the current number first, then [change your mobile number](change-phone.md).
