# Getting started

Expert witnesses [sign in](https://app.superinsight.ai/app/login) on a computer. Use the email on your account. If that email is on Version 1 and Version 2, the page asks which one you want before it sends a code. You do not need a password.

## Sign in

1. Open the expert door and choose **Sign in**.
2. Enter the email on your account and choose **Continue**.
3. On **Check your inbox**, enter the six-digit **Email code** and choose **Sign in**. Or open the **Sign in** button in the same email. The subject is **Your Superinsight sign-in code**. The code and the link expire in 15 minutes.
4. If this browser is remembered, you may see **Checking this browser…** before the code arrives.

If the code expired, the page says **That code expired — send a fresh one below.** Choose **Send another code**. To start over, choose **Use a different email**.

## Create an account

Choose **Create account**. The heading is **Create your expert account**. Enter your email and choose **Create account**. We email the same six-digit code and link. You can look around right away. Upload a CV, fee schedule, and US W-9 so we can verify you. Until those are in, you will be matched less often.

If you already have an account, stay on **Sign in**. Choosing **Create account** with an email we already know still sends a code to that inbox.

A new account asks **How should attorneys address you?** Enter your first and last name, and a credential if you use one, then choose **Continue**.

## Version 1 or Version 2

Some email addresses also belong to the earlier Superinsight app. After you enter that email, the page says **You are signing in as** that address and offers:

- **Sign in to Version 1** — the earlier app.
- **Sign in to Version 2** — this expert workspace. This sends the code.

**Not you? Sign in as another user** clears the remembered address. An invitation to a law firm never shows this choice. **Create account** skips it too.

## An authenticator code

When two-factor authentication is on, a sign-in from a new device or a new location asks for a code from your authenticator app before you reach home. A browser you have used from that place goes straight in.

If you do not have the app, enter a recovery code instead. If you have not enrolled yet and the page asks you to set one up, you can choose **Skip for now**.

To turn it on later, open **Settings**, then **Security**, and enroll an authenticator app. Save the recovery codes. They are shown once. See [The phone app](phone.md#security) for the same steps on a phone.

## Join with a CV, fee schedule, and W-9

After you create an account, the home page says **New expert setup** and **Build your matching profile from three documents**. There is no application form.

1. Upload your **CV**, **fee schedule**, and **W-9**, one file at a time. The page counts **0 of 3 documents** as you go. You can leave and come back. You land on the next file still needed.
2. If we cannot read a file, replace it. The page names the file.
3. Outside the US and without a W-9, choose **Message Support**.
4. When all three are in, review the profile we built and choose **This is accurate**. If we only have a few details, the button is **Yes, this is me**.

Confirming the profile opens your first case. If Superinsight has already assigned you a case, you first choose **Create a new case** or **Open an ongoing case**. With more than one assignment, pick which case to open.

A last optional step asks for a profile photo. **Skip for now** is allowed. After the CV, fee schedule, and W-9 have been read, we email you how to sign in next time.

We still have to approve a new profile before you are matched. If we cannot approve it, the page says why and how to reach us.

## Review a profile we already built

If your email was already in the expert network, the first screen says **You were already in our expert network** and **Welcome — review the profile we started for you**.

1. Read the credentials, specialties, and publications we filled in.
2. Choose **This is accurate**.
3. Upload any missing CV, fee schedule, or W-9 on that same screen. Corrections are on the profile. Photo and bio can wait.
